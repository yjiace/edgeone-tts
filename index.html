API 接口使用说明
POST /v1/audio/speech
Headers: Authorization: Bearer <API_KEY>
Body (JSON): 
{
  "input": "要合成的文本",
  "voice": "zh-CN-XiaoxiaoNeural",
  "speed": 1.0,
  "pitch": 1.0,
  "volume": 1.0,
  "style": "general",
  "styleDegree": 1.0,
  "format": "audio-24khz-48kbitrate-mono-mp3"
}
GET /v1/audio/speech
适合阅读 APP (如 Legado) 直接调用。
Query 参数:
  • text: (必填) 要合成的文本
  • voice: 发音人角色
  • speed / pitch / volume: 范围 0.5 ~ 2.0
  • style: 情感风格 (如 general, cheerful)
  • styleDegree: 风格强度 (0.01 ~ 2.0)
  • format: 输出音频格式
  • token: API 密钥
调用示例:
/v1/audio/speech?text=你好世界&voice=zh-CN-YunxiNeural&speed=1.2&token=API_KEY
